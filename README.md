# Flashcard Quiz App

A simple, responsive flashcard study app built with HTML, CSS, and JavaScript.

## Features
- View questions and reveal answers
- Navigate using Next and Previous
- Add, edit, and delete flashcards
- Automatically save cards in browser Local Storage
- Responsive design for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript
- Local Storage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser, or use VS Code Live Server.

## Note
Flashcards are stored in the browser's Local Storage. Clearing browser storage will remove saved cards.
